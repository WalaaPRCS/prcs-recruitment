# Architecture (initial proposal)

- Frontend: React + TypeScript
- Backend: Node.js + TypeScript API
- Database: PostgreSQL
- Deployment: Docker Compose on Coolify
- Authentication: role-based access with server-side authorization
- Storage: private document storage with access checks
- Operations: audit log, backups, health checks, and migrations

These are proposed choices, not yet implemented. Confirm business workflows and approval roles before development.
